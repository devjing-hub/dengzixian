🌐 发布到 GitHub Pages

  1. 在 GitHub 注册账号并新建一个仓库（例如 reaction-website）。
  2. 把本网站整个文件夹（含 index.html、css、images 等）上传到仓库。
  3. 进入仓库 Settings → Pages，在 Source 里选择 main 分支 并保存。
  4. 稍等片刻，GitHub 会生成主页地址：https://你的用户名.github.io/reaction-website/。
  5. 把这个地址提交给老师即可。

提示：所有页面和图片都使用相对路径（如 css/style.css、images/hero.svg）， 因此无论放在本地还是 GitHub Pages 的任意子目录里，链接都不会失效。
